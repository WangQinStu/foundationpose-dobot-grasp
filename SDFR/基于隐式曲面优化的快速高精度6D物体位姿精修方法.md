## 环境配置

```bash
conda create -n sdfr python=3.8
pip install -r requirement.txt
cd lib/extensions
chmod +x build_ext.sh && ./build_ext.sh
```

## 数据集准备与运行命令
准备obj（标准），单位毫米（mm），若其他单位，请自行转换为毫米（mm）。
models_info.json 文件为脚本prepare_json.py 生成，使用时更改路径即可。
并按如下目录结构放置，ply文件按照obj_000001.ply、obj_000002.ply....命名：
```bash
.
├── datasets
│   ├── models
│   │   ├── lm
│   │       └── models_info.json
│   │       └── obj_000001.ply
│   ├── render
│   │   ...
```
然后运行以下脚本生成数据集：
```bash
python prepare_dataset.py --root-dir [数据集路径] --mode ['standard' 'noise','scale','diverse','corrupt'] 
```

结果将保存至 `render` 目录。

## 运行 SDFR 完整流程

```bash
python run_sdfr.py --root-dir [数据集路径] --mode ['standard' 'noise','scale','diverse','corrupt']
```

## 调试
```bash
python run_sdfr.py --vis-debug --target-obj [数据集路径]
```

## 手动推理
```
1、运行my_tools/calculate_offset.py生成模型抓取点
2、运行my_tools/inference.py 更改相应路径（模型、rgb、内参、抓取点、观测点云、抓取点、初始位姿等）
```
